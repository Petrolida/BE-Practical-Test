## Questions

- Display all users from Surabaya.
  *Tampilkan seluruh user yang berasal dari Surabaya.*

- Display the user name, user's origin, item name, and item price for each order.
  *Tampilkan nama pengguna, asal pengguna, nama barang, dan harga barang untuk setiap pesanan.*

- Calculate the total expenditure for each user based on `total_harga`. Display the user's name, origin, email, and total expenditure. Sort the results from highest to lowest.
  *Hitung total pengeluaran untuk setiap pengguna berdasarkan `total_harga`. Tampilkan nama, asal, email, dan total pengeluaran pengguna. Urutkan hasilnya dari yang tertinggi hingga terendah.*

- Display the item name, total quantity sold, and total revenue for each item. Include only items that have been ordered. Sort the results by total revenue, from highest to lowest.
  *Tampilkan nama barang, total kuantitas yang terjual, dan total pendapatan untuk setiap barang. Sertakan hanya barang-barang yang telah dipesan. Urutkan hasil berdasarkan total pendapatan, dari yang tertinggi hingga terendah.*
